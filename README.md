\- Delete Todo

\- Flask Backend

\# Installation



\## 1. Clone Repository



git clone https://github.com/harsha5200-d/TODO-FLASK.git



\---



\## 2. Move Into Project Folder



cd TODO-FLASK



\---



\## 3. Create Virtual Environment



python -m venv venv



\---



\## 4. Activate Virtual Environment



\### Windows



venv\\Scripts\\activate



\---



\## 5. Install Dependencies



pip install -r requirements.txt



\---



\## 6. Run Flask Application



python app.py



\---



\# Open In Browser



http://127.0.0.1:8000
